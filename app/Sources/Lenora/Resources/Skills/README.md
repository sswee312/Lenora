# lenora-skills

Curated and community skills for [Lenora](https://github.com/vermatushar/lenora), the
AI-native macOS video editor.

## Quickstart

### Install inside Lenora

Go to Settings -> Skills. It will fetch the catalog and allows you to choose and download the skills to `~/.lenora/skills/`.
